# Sample reports

Each sample is a real report on a public codebase, with its module map and the exact commands to
reproduce it.

| Sample | Shows |
|---|---|
| [Earthworm](earthworm/index.md) | a large C system: 929 units, bundled libraries kept apart, files the build skips, and complexity checked against lizard |
| [libmseed](libmseed/index.md) | test coverage imported from gcc and checked against gcovr, file by file |

The full output of each run (the JSON and the per-function tables) is regenerated by the commands in
each sample rather than committed.
